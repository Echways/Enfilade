# Настройка

[English](../en/configuration.md) · [Русский](configuration.md) · [Документация](README.md)

Параметры читаются из секции конфигурации `Enfilade`. Код, переданный в `AddEnfilade`, имеет приоритет. Неверные параметры останавливают запуск.

```json
{
  "Enfilade": {
    "Brand": "Orders",
    "LoginPath": "login",
    "Languages": ["en", "ru"]
  }
}
```

```csharp
builder.Services.AddEnfilade(shell => shell.Appearance = Appearance.System);
```

## Параметры

| Параметр                | По умолчанию | Описание                                        |
| ----------------------- | ------------ | ----------------------------------------------- |
| `Brand`               | `Enfilade` | Название в навигации и в заголовках документов. |
| `ShowVersion`         | `true`     | Показывает версию Enfilade под названием.       |
| `Favicon`             | —           | Путь к значку среди статических файлов.         |
| `Language`            | `en`       | Язык по умолчанию. Должен входить в `Languages`. |
| `Languages`           | —           | Языки, предлагаемые в переключателе.            |
| `LoginPath`           | —           | Страница входа. Делает панель закрытой.         |
| `SignOutPath`         | —           | Эндпоинт выхода.                                |
| `Appearance`          | `Dark`     | `Dark`, `Light` или `System`, чтобы следовать устройству. |
| `Accent`              | —           | Фирменный цвет вместо Klein в виде `#RRGGBB`.   |
| `TimeZone`            | —           | Идентификатор часового пояса для всех зрителей, например `UTC` или `Europe/Berlin`. Без него каждый зритель видит свой пояс. |
| `AutoRefreshInterval` | `00:00:30` | Период `AutoRefresh`.                         |

## Проверка

Параметры проверяются при запуске приложения, поэтому опечатка не ждёт, пока её найдёт пользователь:

- `Language` входит в `Languages` (если `Languages` задан).
- `TimeZone` — часовой пояс, известный хосту.
- `Accent` — цвет в формате `#RRGGBB`.
- `AutoRefreshInterval` больше нуля.

## Окружения

Поскольку параметры читаются из конфигурации, переопределения по окружениям работают как обычно: например, другой `Brand` в `appsettings.Staging.json`, чтобы тестовую панель не приняли за боевую.
