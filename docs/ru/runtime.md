# Поведение во время работы

[English](../en/runtime.md) · [Русский](runtime.md) · [Документация](README.md)

- Исключение на странице локализуется: навигация продолжает работать, а страница предлагает повторить. При переходе страница восстанавливается.
- Когда соединение обрывается, диалог переподключения показывает следующую попытку. Приостановленные каналы (circuits) можно возобновить.
- После навигации фокус переходит на заголовок страницы.
- Макеты учитывают безопасные зоны экрана, грубые указатели и `prefers-reduced-motion`.

## Свежесть данных

Блоки, которые загружают данные, перезагружаются в трёх случаях:

1. После действия через `Button`, `Act` или `Form`.
2. Когда пользователь нажимает на отметку обновления в `PageHead`.
3. Каждые `AutoRefreshInterval`: для `Listing` с `Live`, для `AutoRefresh` и для счётчиков в навигации, и только пока вкладка браузера видна.

Перезагрузка оставляет на экране то, что есть, и заменяет это, когда приходят данные; неудачная перезагрузка сообщает об этом внутри блока и не трогает остальную страницу. О `CurrentPage` см. [Действия](actions.md).

## Сбои

Загрузка списка, которая не удалась, счётчик, который не смог посчитать, и действие, бросившее исключение, — всё это локализуется там, где произошло. Первые два до остальной страницы не доходят; последнее показывается пользователю, как описано в [Сообщениях об ошибках](errors.md).
