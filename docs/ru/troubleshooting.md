# Частые проблемы

[English](../en/troubleshooting.md) · [Русский](troubleshooting.md) · [Документация](README.md)

Enfilade проверяет всё, что может, при запуске или при первом рендере и называет причину в сообщении. Здесь собраны самые частые случаи.

## При запуске

| Сообщение относится к | Причина | Что делать |
| --------------------- | ------- | ---------- |
| `Language` | Язык по умолчанию не входит в `Languages`. | Добавьте его в `Languages` или смените `Language`. |
| `TimeZone` | Хост не знает такой идентификатор часового пояса. | Возьмите идентификатор из `TimeZoneInfo.GetSystemTimeZones()`, например `Europe/Berlin`. В урезанном образе контейнера установите `tzdata`. |
| `Accent` | Не цвет `#RRGGBB`. | Передайте шесть шестнадцатеричных цифр с `#`. |
| `AutoRefreshInterval` | Ноль или отрицательное значение. | Задайте положительный интервал. |
| «has no @page route without parameters» | У страницы раздела есть только маршруты с параметрами. | Добавьте маршрут без параметров либо зарегистрируйте страницу через `AddPages` и дайте на неё ссылку сами. |

## При первом рендере страницы

| Ситуация | Что делать |
| -------- | ---------- |
| У `Listing` заданы и `Load`, и `Items`, или ни один. | Передайте ровно один. |
| У сортируемой `Cell` нет пути к члену (вычисляемый `Value`). | Добавьте `Key`. |
| У двух фильтров списка одно имя. | Дайте каждому своё `Name`. |
| Выбираемый список с `Load` и элементами, которые не records. | Добавьте `ItemKey`. |
| `Field` над неизвестным ему типом. | Используйте ввод MudBlazor с `For=` внутри `Form`. |
| Два `Tabs` на одной странице. | Дайте каждому своё `Name`. |
| Два `Listing` на одной странице. | Дайте каждому своё `Name`, чтобы ключи адреса не пересекались. |

## Поведение

**Раздела нет в меню.** У его страницы есть `[Authorize(Roles = ...)]` или `[Authorize(Policy = ...)]`, которым текущий пользователь не соответствует. Так и задумано.

**Всех бесконечно перенаправляет на страницу входа.** Когда задан `LoginPath`, самой странице входа нужен `[AllowAnonymous]`.

**Страница по ссылке показывает «Нет доступа».** Пользователь вошёл, но не проходит по роли или политике страницы. Так и задумано.

**Кнопка копирования сообщает, что скопировать нельзя.** Доступ к буферу обмена требует HTTPS (или `localhost`). Отдавайте панель по HTTPS.

**Время отличается на час.** Храните значения в UTC. Часовой пояс зрителя браузер сообщает один раз за соединение; если он не сообщил, панель использует UTC. Чтобы показывать всем один пояс, задайте `TimeZone`.

**Аутентификация на панель не действует.** `MapEnfilade` должен стоять после `UseAuthentication` и `UseAuthorization`.

**Нет счётчика.** Нулевое значение ничего не показывает. Подсчёт, который упал, пишется в лог и пропускается; ищите его там.

**Текст исключения пользователю не показан.** Показываются только `PanelException` и исключения, зарегистрированные через `ShowMessageOf`. Остальным достаётся общее сообщение, и они пишутся в лог. См. [Сообщения об ошибках](errors.md).
