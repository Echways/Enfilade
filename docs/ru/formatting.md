# Форматирование

[English](../en/formatting.md) · [Русский](formatting.md) · [Документация](README.md)

`Words` единообразно форматирует значения в текущей культуре.

| Метод                          | Пример                                                                     |
| ------------------------------ | -------------------------------------------------------------------------- |
| `Number(1284)`               | `1,284`                                                                  |
| `Size(1536)`                 | `1.5 KB`                                                                 |
| `Duration(1240)`             | `1.2 s`                                                                  |
| `Share(0.123)`               | `12.3%`                                                                  |
| `Middle(text, 10)`           | `tnk_AB…XYZ`                                                            |
| `Count(pattern, n)`          | ICU-множественные: `{n, plural, one {{number} order} other {{number} orders}}` |
| `Of(value, zone)`             | Любое из этого по типу, время в `zone`, `–` для `null`                  |
| `Day`, `Minute`, `Clock`  | `2026-10-26`, `2026-10-26 14:05`, `14:05` в заданном поясе              |

Примеры даны для английской культуры; в русской изменятся, например, разделители.

## Время зрителя

`ViewerTime` — те же методы со стороны зрителя. Это сервис соединения, поэтому страница или компонент внедряют его, а его часовой пояс сохраняется, откуда бы ни начался рендер, включая обновления, присланные из фоновой работы.

```razor
@inject ViewerTime Viewer

<span>@Viewer.Minute(order.CreatedAt)</span>
```

| Член                           | Назначение                                                               |
| ------------------------------ | ------------------------------------------------------------------------ |
| `Of(value)`                   | `Words.Of` в часовом поясе зрителя                                      |
| `Day`, `Minute`, `Clock`  | `2026-10-26`, `2026-10-26 14:05`, `14:05` в часовом поясе зрителя     |
| `ToViewer`, `FromViewer`    | Момент в UTC в местное время зрителя и обратно                           |
| `Zone`                        | `TimeZoneInfo` зрителя                                                  |

Время показывается в часовом поясе зрителя, который браузер сообщает один раз за соединение. Браузер, не сообщивший пояс или сообщивший неизвестный, получает UTC. Чтобы показывать всем один пояс, задайте `TimeZone`. Данные храните в UTC: блоки значения хоста никогда не меняют.

## Множественное число

`Count` принимает ICU-шаблон, поэтому правильная форма выбирается в каждом языке, у которого есть правила множественного числа:

```csharp
Words.Count("{n, plural, one {{number} order} other {{number} orders}}", orders.Count)
```
