# Сообщения об ошибках

[English](../en/errors.md) · [Русский](errors.md) · [Документация](README.md)

`Act`, `Button`, `Form` и `Listing` показывают пользователю сообщение `PanelException`. Другие исключения, чьи сообщения предназначены для пользователя, например доменное исключение из библиотеки, которая ничего не знает о панели, нужно зарегистрировать:

```csharp
builder.Services.AddEnfilade()
    .ShowMessageOf<DomainException>(failure => Words.Sentence(failure.Message));
```

- Регистрация действует на исключение и его наследников. Регистрации опрашиваются по порядку, побеждает первое сообщение; вернув `null`, вы передаёте исключение следующей.
- `ShowMessageOf` есть и у `IServiceCollection`, так что библиотека может зарегистрировать свои исключения без билдера. Если для сообщения нужны сервисы, зарегистрируйте реализацию `IErrorMessage`.
- Внедрите `ErrorMessages` и вызовите `Of(exception)`, чтобы получить сообщение в своих компонентах; для исключения, которое пользователю видеть не нужно, вернётся `null`.
- Показанное сообщение в лог не пишется; любое другое исключение пишется.

## Что видит пользователь

| Исключение | Сообщение | В лог |
| ---------- | --------- | ----- |
| `PanelException` | Его собственный текст | Нет |
| Зарегистрированное исключение | Текст, который вернула регистрация | Нет |
| Любое другое | Общее сообщение без внутренних подробностей | Да |

Исключение, вырвавшееся со страницы, панель не роняет. См. [Поведение во время работы](runtime.md).
